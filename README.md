# CodeSloth Cursor Samples

Public sample projects that accompany [Code Sloth](https://codesloth.blog/) posts about Cursor AI skills, workflows, and agent automation.

Each sample lives in its own project folder with a local `.cursor/` tree so you can open that folder in Cursor and use the skill as shipped for that article — without inheriting later, more complex versions.

## Samples

| Folder | Blog post | Skill |
|--------|-----------|--------|
| [`team-brain-intro/`](team-brain-intro/) | [Building Scalable Skills for Agentic Workflows](https://codesloth.blog/building-scalable-skills-for-agentic-workflows/) | `team-brain-intro` |

## How to try a sample

1. Clone this repository.
2. In Cursor, **Open project** on the sample folder (for example `team-brain-intro/`), not necessarily the repo root.
3. Invoke the skill by name (for example `/team-brain-intro`) and ask a question that matches one of its intents.

See the Code Sloth [Code Samples](https://codesloth.blog/code-sloth-code-samples/) page for the full list of public repositories.
